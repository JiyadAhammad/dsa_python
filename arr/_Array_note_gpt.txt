Array
    What is an Array?
    An array is a fundamental data structure used to store a collection of elements of the same data type under a single variable name.
    Example:
    arr = [10, 20, 30, 40]

Key Characteristics of Arrays
    1. Contiguous Memory Location
        Elements are stored in adjacent memory locations.
        Because of this, accessing an element by index takes:
        Time Complexity: O(1)

    2. Index-Based Access
        Each element has a unique index.
        Index:  0  1  2  3
        Array: [10,20,30,40]
        Most programming languages use 0-based indexing.

    3. Homogeneous Elements
        Arrays traditionally store elements of the same data type.
        int arr[5];
        All elements are integers.

    4. Fixed Size
        In languages like C/C++ and Java, array size is fixed once created.
        int arr[5];
        Size cannot be changed during runtime.
        Note:
        Python lists and Dart Lists are dynamic arrays and can grow or shrink.

Common Time Complexities:
    Operation	            Complexity
    Access	                O(1)
    Search	                O(n)
    Insert at End	        O(1) amortized
    Insert at Beginning	    O(n)
    Delete	                O(n)

Important Array Patterns
1. Two Pointers
    What is it?
    Uses two indices/pointers to traverse the array efficiently.
    Instead of nested loops:
    Brute Force → O(n²)
    Two Pointers → O(n)

When to Use
    ✅ Sorted Array
    ✅ Pair Problems
    ✅ Reversing Array
    ✅ Removing Duplicates
    ✅ Partitioning Problems

Common Problems
    Two Sum II
    Three Sum
    Container With Most Water
    Sort Colors
    Remove Duplicates from Sorted Array

2. Sliding Window
    What is it?
    Maintains a contiguous window and moves it across the array.
    Reduces:
    O(n²) → O(n)
        Types
            Fixed Size Window
                Maximum Sum Subarray of Size K
            Variable Size Window
                Longest Substring Without Repeating Characters

When to Use
    ✅ Contiguous Subarrays
    ✅ Contiguous Substrings
    ✅ Maximum/Minimum Problems
    ✅ Optimization Problems

3. Prefix Sum
    What is it?
    Precompute cumulative sums.
    Given:
    [1, 2, 3, 4]
    Prefix Sum:
    [1, 3, 6, 10]
    Formula
    prefix[i] = prefix[i-1] + arr[i]
    Range Sum Query
    sum(l,r) = prefix[r] - prefix[l-1]

When to Use
    ✅ Frequent Range Sum Queries
    ✅ Subarray Sum Problems
    ✅ Matrix Sum Queries
    ✅ Equilibrium Index

4. Kadane's Algorithm
    What is it?
    Finds the maximum sum contiguous subarray.
    Idea
    At every index:
    Either:
    Start a new subarray
    OR
    Extend existing subarray
    Complexity
    Time : O(n)
    Space: O(1)

When to Use
    ✅ Maximum Subarray Sum
    ✅ Contiguous Subarray Problems
    ✅ Optimization Problems

Important Note
The standard Kadane's Algorithm returns the largest element when all numbers are negative.
